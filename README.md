# React Movie App 🎬

A responsive and deployable **movie web application** built using **React.js** and **Tailwind CSS**, designed to help understand the core fundamentals of React while creating an interactive project. The app fetches real movie data using a public movie API and presents it in a clean, modern interface.

**Live Demo:** [cinematicx.vercel.app](https://cinematicx.vercel.app)

---

## 🚀 Features

- Developed using **React.js** with functional components and hooks  
- Styled entirely with **Tailwind CSS** for a modern and responsive UI  
- Integrated **movie API** to dynamically fetch real-time movie data  
- Includes **search functionality** for querying movie titles  
- Displays detailed information such as overviews, ratings, and release dates  
- **Responsive UI** across all screen sizes (mobile-first approach)  
- **Deployed on Vercel** for effortless and fast hosting

## ⚙️ Installation & Setup

Follow these steps to run the project locally:

1. Clone this repository:
git clone https://github.com/Veer2401/react-movie-app.git

text
2. Navigate into the project folder:
cd react-movie-app

text
3. Install dependencies:
npm install

text
4. Run the application locally:
npm start

text
5. Visit [**http://localhost:3000/**](http://localhost:3000/) in your browser.
